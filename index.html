Chapter 01 — About

The story so far

I like learning, building, and turning cloud complexity into something people can actually use.

I'm April — a cloud engineer who found her way into tech through curiosity and a lot of late-night documentation. I care less about buzzwords and more about whether the thing actually works for the person on the other end.

I started in data, making sense of datasets for the Quezon City local government, then moved into IT operations and cloud support. Somewhere along the way I fell for AWS — and haven't stopped since. Today I'm a Technical Support Engineer at Valueline Systems, a 3× AWS Certified cloud practitioner, an AWS Community Builder, and a published author at Tutorials Dojo writing about AI, MCP servers, and cloud infrastructure.

When I'm not troubleshooting cloud environments or writing, you'll find me helping run developer communities — from AWS BuildHers+ to Python Philippines — because the best way to learn is to build alongside other people.

Currently — deep in AWS Bedrock & agentic AI, building demo chatbots and writing about where cloud meets AI.
